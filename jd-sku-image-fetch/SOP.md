# 操作 SOP · 京东SKU主图抓取

> **这份文档给谁看**：不懂命令行、只想把活干完的人。
> **照着做完，你能得到**：一份按榜单命名的 Excel，里面每个商品旁边直接嵌好了主图，
> 还带标题、价格、累计评价数、营销活动、店铺 —— 点图能看 800×800 原图。

# 第一部分 · 一次性准备

> 只在**第一台电脑上做一次**。以后每天用只需要走第二部分。

## 步骤 1：装 Python

1. 打开 <https://www.python.org/downloads/>
2. 下载 **3.10 或更新**的版本，双击安装
3. ⚠️ **安装第一个界面，务必勾上 `Add python.exe to PATH`**
   这一项不勾，后面所有脚本都找不到 Python，是最常见的失败原因
4. 装完**重启电脑**（或至少关掉所有命令行窗口）

> 已经有 Python 了？跳过，直接下一步。

## 步骤 2：装 bsk + 浏览器扩展

**bsk** 是驱动你**真实浏览器**的工具 —— 它复用了你浏览器的指纹、你的登录账号、
你的本地网络。这是绕过京东风控的关键（普通脚本一抓就被拦）。

1. 按 `Win` 键，搜 **PowerShell**，打开
2. 粘贴这一行，回车：

   ```powershell
   irm https://raw.githubusercontent.com/Tencent/BrowserSkill/main/install.ps1 | iex
   ```

3. 装完**关掉 PowerShell 再重新打开**，输入 `bsk --version`，能出版本号就算成功
4. 在 **Chrome 或 Edge** 里安装 **BrowserSkill 扩展**并启用
   （这一步必须人工做，没有任何办法代劳）

## 步骤 3：双击 setup.bat（一键安装）

在工具文件夹里找到 **`setup.bat`**，**双击**。

它会自动干完这些事，你只需要看它跑：

- 找到电脑上的 Python
- 如果依赖已经有了 → 直接复用，**什么都不装**
- 如果没有 → 在工具文件夹里建一个**私有的 `.venv`** 环境并装好 openpyxl + Pillow
  （**不会污染你的系统环境**，想反悔直接删掉 `.venv` 文件夹即可）
- 自动生成一份 `skus.csv`（模板，后面不用可以不管）
- 检查 bsk 状态
- 最后跑一次**全面自检**，把缺的东西列出来

**看到这一行就成功了：**

```
结论：环境就绪，可以开始抓取。
```

如果看到 `[FAIL]` 或 `[WARN]`，看它下面的 `->` 提示照着做，或者对照本文最后的
「常见问题」表。

## 步骤 4：启动常驻服务

双击 **`start-bsk-daemon.bat`**。

- 会弹出一个黑色窗口，**这个窗口不能关**，关了服务就停了
- 建议把它**最小化**，一直留着
- 可以把它拖到任务栏固定，下次一键启动

## 步骤 5：登录京东（只做一次）

1. 在 bsk 连着的那个 Chrome / Edge 里，打开 <https://www.jd.com>
2. **手动登录**你的京东账号（扫码或密码都行）
3. 登录状态会**长期保存**，以后不用反复登录

> 注意：登录、验证码、支付这类操作**必须你自己点**，任何工具都不该也不会代你操作。

## ✅ 准备完成检查

双击 `run.bat`，选 **8**（环境自检）。出现下面这样的结果就可以正式用了：

```
[ OK ] Python 版本       3.12.x
[ OK ] 依赖 openpyxl     ...
[ OK ] 依赖 Pillow       ...
[ OK ] bsk CLI           ...
[ OK ] bsk 守护进程      ok daemon running ...
[ OK ] 浏览器扩展        ok extension connected 1 browser(s) connected
结论：环境就绪，可以开始抓取。
```

# 第二部分 · 日常操作

## 步骤 1：拿到榜单

从京东后台导出榜单 Excel（一般 200 个 SKU），放到桌面或任意文件夹。

> 文件名随便，脚本会**自动从文件名推断榜单名**，用它给输出目录和表格命名。

## 步骤 2：跑抓取

1. 确认 **`start-bsk-daemon.bat` 的窗口还开着**（第一步的常驻服务）
2. 双击 **`run.bat`**
3. 输入 **`2`**，回车（从 xlsx 抓）
4. 把榜单文件**用鼠标拖进这个黑窗口**，然后回车
5. 它问你「本次抓几个」→ 输入数字后回车

   > **建议输入 25 到 30**。别贪多，理由见下面「反风控纪律」。

6. 看着它一个个跑，每个大约 3~8 秒

## 步骤 3：拿结果

跑完会自动生成 Excel，**不用你再操作**。文件位置：

```
<工具文件夹>\runs\<榜单名>_<日期>\<榜单名>_<日期>.xlsx
```

例如：`runs\商品榜单_热销排名_20260930\商品榜单_热销排名_20260930.xlsx`
（榜单名从你的 xlsx 文件名自动推断，日期是抓取当天）

打开它，你会看到：

| 列 | 内容 |
|---|---|
| A–I | SKU / 状态 / 标题 / 价格 / **累计评价数** / **营销活动** / 店铺 / 图数 / 图片文件名 |
| **J** | **商品主图**（直接显示，不用点链接） |
| K–M | 商品链接 / 备注 / 抓取时间 |

**点图片 = 打开 800×800 原图**（画质不受表格里的缩略图影响）。

# 第三部分 · 纪律（很重要，别跳过）

## 反风控纪律

京东的风控看的是**频率**。我们实测出来的边界（2026-09-29）：

> 一次连续跑到 **第 34 个**时，开始被京东拦（返回 403）。
> 也就是说 **约 34 个 / 5 分钟** 就是当前阈值。

**所以按这个节奏来：**

| 项目 | 建议值 | 说明 |
|---|---|---|
| 每批数量 | **25 ~ 30 个** | 别贴着 50 抓 |
| 批间隔 | **10 ~ 15 分钟** | 跑完一批，去干点别的再回来 |
| 每日总量 | **100 ~ 150 个** | 长期稳定运行的上限 |
| 被拦之后 | **等 15 ~ 30 分钟** | 别立刻重跑，越急越拦 |

**分辨是不是被拦了**：执行日志里出现 `reason=403` 或 `pf.jd.com`，
表格里那一行的「状态」列是 `risk`。

**好消息**：脚本自带保护 —— 连续 3 次失败会**自动停下来**，不会傻冲；
已经抓好的**不会丢**，重跑会自动跳过已完成的，只补没抓到的。

## 三条不要做

1. **不要**把每批数量调到 50 去跑 —— 一定被拦
2. **不要**被拦后连着重试 —— 会拉长封禁时间
3. **不要**关掉 `start-bsk-daemon.bat` 的窗口 —— 服务一停，抓取必失败

# 第四部分 · 常见问题

| 现象 | 原因 | 怎么解决 |
|---|---|---|
| 双击 `run.bat` 一闪而过 | 没装 Python，或装时没勾 `Add to PATH` | 重装 Python，**务必勾** `Add python.exe to PATH`，然后双击 `setup.bat` |
| 提示 `openpyxl / Pillow are missing` | 依赖没装 | 双击 **`setup.bat`**，它会自动装好 |
| 提示 `bsk not found on PATH` | bsk 没装，或装完没重开窗口 | 按步骤 2 装 bsk，**关掉窗口重新打开** |
| 自检里 `daemon` 是 FAIL | 常驻服务没启动 | 双击 **`start-bsk-daemon.bat`**，窗口别关 |
| 自检里 `extension connected` 是 0 browser | 浏览器没开，或扩展没启用 | 打开 Chrome，确认 BrowserSkill 扩展已启用 |
| 状态列大面积 `risk` | 抓太快被风控 | 立刻停，等 15~30 分钟；下次把每批降到 25 |
| 状态列是 `no_image` | 页面正常但没取到主图 | 用菜单 **5**（Force refetch）重抓这几个 |
| 表格打开是乱码/错行 | 用 Excel 直接开了 `report.csv` | 请开 **`.xlsx`** 那份，不要开 csv |
| 导出时报「表格被占用」 | Excel 正开着这个文件 | 先关掉 Excel，再重新导出（菜单 **6**） |
| 跑一半卡住不动 | 网络慢或页面加载慢 | 耐心等一会；超过 2 分钟没反应就 `Ctrl+C` 停掉，重跑会接着来 |
| 想换个榜单名/自己命名 | 默认按文件名自动命名 | 命令行加 `--run-name "618大促_某店_20260601"` |

# 第五部分 · 三个入口，选一个用

| 你是哪种人 | 用这个 |
|---|---|
| **不想碰命令行** | 双击 `setup.bat`（一次性）→ 双击 `run.bat`（日常）。**看本文档就够了** |
| **想用 WorkBuddy / AI 助手代劳** | 直接对 AI 说：**"用京东SKU主图抓取技能，帮我抓这份榜单的主图"**，并把 xlsx 给它 |
| **习惯命令行 / 要接自动化** | 见下方「命令速查」 |

## 命令速查

```bash
# 环境自检（首次 / 出问题先跑这个）
python doctor.py                # 或 run.bat 8

# 从榜单 xlsx 抓（只看前 50 名，本次抓 25 个）
python fetch_main_images.py . --from-xlsx "榜单.xlsx" --top 50 --limit 25

# 从 skus.csv 抓
python fetch_main_images.py . --top 50 --limit 25

# 看进度 / 看所有批次
python fetch_stats.py
python fetch_stats.py --all

# 导出嵌图 Excel（跑完自动执行，一般不用手动）
python export_images_xlsx.py .
python export_images_xlsx.py . --all-runs

# 修复/体检 report.csv
python fix_report_urls.py .
python fix_report_urls.py . --apply
```

`run.bat` 也支持非交互调用（执行完直接退出，适合脚本或 AI 调用）：

```bash
run.bat 4          # 等于菜单里选 4
run.bat stats      # 命名入口：stats / doctor / export / repair / bsk
```

# 附：文件都放在哪

```
工具文件夹\
├─ setup.bat              ← 一次性安装（双击）
├─ run.bat                ← 日常操作菜单（双击）
├─ start-bsk-daemon.bat   ← 常驻服务（双击后别关）
├─ doctor.py              ← 环境自检
├─ skus.csv               ← 你的 SKU 清单（可选）
└─ runs\                  ← 所有抓取结果都在这里
   └─ <榜单名>_<日期>\
      ├─ <榜单名>_<日期>.xlsx   ★ 最终成品，带嵌图
      ├─ report.csv             原始数据
      ├─ images\                下载好的主图原图
      ├─ state.json             进度（断点续传用）
      └─ logs\                  运行日志
```

**每次抓不同榜单，都会新建一个 `runs\<榜单名>_<日期>\` 文件夹，
图片和表格绝不会跟别的榜单混在一起。**
