## 概述

- **仓库用途**: 个人电商工具项目集，用于面试展示
- **技术方向**: Python 为主，涵盖竞品监控、数据分析、内容生成、数据采集
- **可见性**: Public
- **维护者**: @237130014

## 仓库策略

- 采用单仓库 (monorepo) 策略，所有项目集中管理
- 每个项目独立目录，包含自己的 README 和依赖
- 顶层 README 作为面试官入口，提供项目导航和亮点提炼

## 项目规划

| 项目 | 方向 | 优先级 | 状态 |
|------|------|--------|------|
| competitor-new-product-monitor | 竞品监控 | P0 | 已上线 |
| quick-analysis | 数据分析 | P0 | 规划中 |
| buyer-show-gen | 内容生成 | P1 | 规划中 |
| content-scraper | 数据采集 | P2 | 规划中 |

## 面试展示要点

1. 顶层 README 一眼能看到所有项目和核心亮点
2. 每个项目可独立运行，面试官能快速 clone 体验
3. 技术亮点部分重点写"遇到什么问题、怎么解决的"
4. 配运行截图，降低面试官了解成本
