小红书热门笔记抓取工具
3 步上手 · 无需懂技术
1
装一次 Python
打开 python.org/downloads 下载安装，安装时务必勾选 Add Python to PATH。
2
双击 setup.bat
自动安装依赖 + 浏览器内核（约 100MB，耐心等几分钟），看到 Setup done! 即可。
3
双击 run.bat
首次会弹二维码，用小红书 App 扫码登录，之后自动复用。抓完自动打开看板网页。
小贴士
· 抓什么关键词：编辑 references/keywords.json 里的词，保存后重新双击 run.bat
· 结果在哪看：xhs-baseline 文件夹（网页看板 + 表格 + 封面图）
