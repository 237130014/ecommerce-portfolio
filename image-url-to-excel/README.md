# 表格图片链接转图片

一句话说明：电商后台导出的表格里，商品图往往只是一列链接，想看款式得一个个点开——把表格拖到 `run.bat` 上，脚本自动把链接下载成缩略图嵌进表格，翻表就能看图。

**不需要懂技术**，按下面三步走就能用。

---

## 三步开始

### 第 1 步：装一次 Python（只需装一次）

1. 打开官网下载：https://www.python.org/downloads/
2. 双击下载好的安装包
3. ⚠️ **安装时务必勾选底部的 `Add python.exe to PATH`**，再点 Install
4. 装完关掉即可

> 电脑里已经装过 Python 的话，这一步跳过。

### 第 2 步：把表格拖到 `run.bat` 上

找到项目文件夹里的 **`run.bat`**，把要处理的表格文件**直接拖到它上面**，松手就开始跑。

也可以双击 `run.bat` 打开窗口，再把表格拖进窗口里、或粘贴路径后按回车。

第一次运行会自动装所需组件（openpyxl / pillow / requests），联网等十几秒就好。

### 第 3 步：看结果

处理完会在**原表格旁边**生成一个 `原文件名_图片版.xlsx`，窗口里会显示完整路径，并自动在文件管理器里定位到它。

- 原表格**不会被改动**
- 图片列插在原来那列链接的**右边**，链接本身保留着，方便核对
- 处理过程中每张图都会显示进度

## 常见问题

**表格能是哪些格式？**
`.xlsx`、`.xlsm`、`.csv` 都行。

**一个格子里有好几个链接怎么办？**
取第一个。电商后台经常把同一张图的多种尺寸塞在一个 JSON 里（比如 `pic400x400`、`pic0x0`、`pic50x50`），排在最前面的通常就是最合适那版。日志会提示有多少个格子属于这种情况。

**图片列的位置能调整吗？**
默认插在链接列右边。想放到别处，处理完在 Excel 里拖动整列即可。

**有些格子显示"下载失败"**
说明那张图拉不下来。常见原因：链接已过期、图片已下架、对方站点防盗链严格。失败的格子会标红字，不影响其他行。

**表格太大跑得慢？**
默认 8 个线程并发下载，一千行大概几分钟，主要取决于图片服务器速度。网络好可以加线程（见下方技术用法）。

**图片想大一点或小一点？**
默认 100×100。`-s 140` 出大图，`-s 60` 更紧凑。图片越大、表格文件越大。

## 给技术同事（可选）

```bash
pip install -r requirements.txt

python url2img.py 商品表.xlsx                    # 默认 100×100，8 线程
python url2img.py 商品表.xlsx -s 140 -w 16       # 换尺寸和并发
python url2img.py 商品表.xlsx --column 主图链接    # 只处理指定列
python url2img.py                              # 交互式，拖入或粘贴路径
python selftest/run_selftest.py                # 跑一遍端到端自测
```

| 参数 | 说明 |
|------|------|
| `-o` | 输出文件，默认 `原文件名_图片版.xlsx` |
| `-s` | 缩略图边长（像素），默认 100 |
| `-w` | 并发线程数，默认 8 |
| `-t` / `-r` | 单张超时秒数 / 失败重试次数，默认 10 / 2 |
| `--referer` | `auto`（按图片域名自动生成，默认）、`none`、或指定地址 |
| `--column` | 只处理指定列，可重复，支持列名或列字母（如 `B`） |
| `--header-row` | 表头所在行号，默认 1 |
| `--open` | 处理完成后在文件管理器里定位输出文件 |

自测会起一个本地图片服务，故意模拟防盗链拦截、扩展名与实际格式不符（WebP 伪装成 `.jpg`）、404 坏链，覆盖 4 组运行 + 3 组单元测试，Windows 下还会连带测 `run.bat` 的拖拽与交互输入。

## 实现上有意思的几处

**防盗链**：京东、淘宝、抖音的图片 CDN 会校验 `Referer`，直接请求给 403 或一张占位图。脚本把 `Referer` 设成图片自己域名下的首页（`auto` 模式），能绕过绝大多数校验。

**扩展名会骗人**：URL 写着 `.jpg`，返回的可能是 WebP 或 AVIF。所以不看扩展名，下载后按真实内容解码，统一转成 JPEG 再嵌入——这也是体积能压得很小的原因（100×100 约 1.5KB）。

**逗号到底是参数还是分隔符**：阿里云 OSS 的 `x-oss-process=image/resize,m_mfit,w_400` 带逗号，而表格又常用逗号分隔同一格里的多张图。两者冲突，所以先按 `http` 起始把文本切成几段分别匹配，再剥掉尾部标点，两种格式都不会错。顺带一提：带 `Signature=` 的签名链接改动任何参数都会 403，所以这类链接只原样请求，不做参数改写。

---

## 注意

- 表格里如果**原本就嵌了图片**，openpyxl 保存时会丢掉它们。脚本开始时会警告，请先确认原表格另有备份。
- 表格里有**合并单元格**时，插入图片列后可能需要手工调整布局，脚本也会提示。
- 同一张图被多个格子引用时，会各存一份（openpyxl 不做媒体去重）。
- 仅供个人工作提效使用，请遵守目标站点的使用条款。
