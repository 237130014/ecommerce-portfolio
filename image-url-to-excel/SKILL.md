# 表格图片链接转图片

把「表格里只有一列图片链接」变成「表格里直接看到图」。服务对象是电商运营：后台导出的数据表通常把商品图存成 URL，核对款式得一个个点开，这个工具一次处理整表。

## 输入与输出

- 输入：`.xlsx` / `.xlsm` / `.csv`，默认全表扫描（`--column` 可限定列）
- 输出：与原表格同目录的 `<原名>_图片版.<后缀>`，**原文件不动**
- 图片列：插在**原 URL 列右侧**，表头为 `<原列名> 图片`；原 URL 列完整保留
- 缩略图：默认 100×100 白底正方形、等比缩放居中、JPEG 存储（约 1.5KB/张）
- 行高列宽按图片尺寸自动设置（行高 = 像素 × 0.75 + 3 pt，列宽 = 像素 ÷ 7 + 0.7）

## 工作流

### Step 1 扫描
`scan_sheet` 遍历所有单元格，用 `find_urls` 提取图片链接；同时也看单元格超链接目标（应对显示文字与链接不一致的情况）。

### Step 2 提取（两个易错点）
- **不能把逗号当边界**：OSS 的 `x-oss-process=image/resize,m_mfit,w_400` 带未转义的裸逗号，而表格又常用逗号分隔同一格的多张图。做法是先用 `(?=https?://)` 切分文本，再逐段匹配，最后 `rstrip(",;.")` 剥掉尾部标点。
- **一格多链接取第一个**：后台常把同一张图的 `pic400x400`/`pic0x0`/`pic50x50` 塞进一个 JSON，第一个通常是尺寸最合适那版。含多链接的格子数会在日志里汇总提示。

### Step 3 下载
- 并发 `ThreadPoolExecutor`，默认 8 线程；按 URL 字符串去重，同一链接只下载一次
- **防盗链**：`Referer` 默认设成图片自己域名下的首页（`auto` 模式），这是绕过京东/淘宝/抖音 CDN 校验的关键
- 失败重试 2 次；带查询串的地址失败后回退裸路径再试一次
- 注意：带 `Signature=` 的 OSS 链接改动任何参数都会 403，裸路径兜底对它无效

### Step 4 转码
不看扩展名，按真实内容解码（`Image.open`）。统一流程：`exif_transpose` → 取 GIF 首帧 → 透明图转 RGBA → LANCZOS 等比缩放 → 贴到白色方画布（透明区垫白，**不能直接 `convert("RGB")`，会变黑**）→ 存 JPEG。

### Step 5 写回
必须**从右往左**插入列，否则前面插过的列会让后面记录的列号整体偏移。用 `ws.add_image(XLImage(路径), 单元格坐标)` 锚定。

**必须传文件路径而非 PIL 对象**：openpyxl 的 `Image._data` 只在 `format in ('gif','jpeg','png')` 时直接读原字节；传内存构造的 PIL 图会走进 `img.fp.seek(0)` 分支，而内存图没有 `fp`，直接报错。传路径才能保留 JPEG 原始字节、体积最小。

### Step 6 交付
- 汇报：命中单元格数 / 不重复链接数 / 成功与失败张数 / 输出路径
- `--open` 时才在文件管理器里定位输出文件，且仅在真控制台（`sys.stdout.isatty()`）下生效，批处理重定向场景不弹窗

## 运行方式

```bash
python url2img.py 商品表.xlsx
python url2img.py 商品表.xlsx -s 140 -w 16 --column 主图链接
python url2img.py                 # 交互式，拖入或粘贴路径
python selftest/run_selftest.py   # 端到端自测
```

Windows 下双击 `run.bat`：自动找 Python（`py -3` → `python` → `python3`）、缺依赖自动装、处理完暂停等你看结果；支持把表格直接拖到 BAT 图标上。

## 关键经验（踩坑记录）

1. **openpyxl 会丢弃已有图片**：`load_workbook` 默认不加载原表嵌入的图片，`save` 后就没了。处理前用 zipfile 检查 `xl/media/` 并告警。
2. **透明 PNG 垫白底**：直接 `convert("RGB")` 会让透明区变黑，必须先转 RGBA 再用 alpha 当蒙版贴白底。
3. **openpyxl 的 drawing XML 没有 `xdr:` 前缀**：默认命名空间下是 `<pic>`、`<from><col>N</col>…<row>N</row>`，用带前缀的写法匹配不到（写测试断言时踩过）。
4. **BAT 中文显示**：UTF-8 保存必须**无 BOM 且 CRLF 行尾**，开头 `chcp 65001`；LF 行尾的 UTF-8 BAT 切代码页后会出现行丢失。Python 输出编码不写死，交给 Windows 控制台自身的 Unicode 通道（PEP 528），与代码页无关。
5. **`str.format` 撞 JSON 花括号**：拼含 `{"key":"..."}` 的测试用例时不能用 `.format()`，会 `KeyError: '"pic400x400"'`。
6. **行高列宽换算**：100px 图 → 行高 78pt、列宽约 15，留余量避免图片盖住相邻行。
7. **media 不去重**：同一张图被 N 个格子引用时，openpyxl 按 image 对象数量写 N 份相同图片数据。

## 输出格式（固定）

- 图片单元格：无文字，只贴图
- 失败单元格：红字 `下载失败`
- 新列表头：`<原表头> 图片`，加粗
